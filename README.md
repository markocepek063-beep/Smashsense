# SmashSense (Fabric 1.21.11)

Mace PvP HUD. Hold a mace and fall: a meter under your crosshair shows your fall distance,
flips to SMASH READY once a smash attack is possible (over 1.5 blocks), and predicts the raw
smash damage (including Density). Display only, no automation. Toggle with /smashsense.

Needs Fabric Loader 0.18.2+, Fabric API, Java 21. Client-side only.
